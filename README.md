# MTools

**Локальные медиа-инструменты в браузере.** Всё работает на вашем компьютере — файлы никуда не отправляются.

## Возможности

### ✂️ Обрезка видео/аудио
- Откройте MP4, WEBM, MP3 или WAV
- Визуальный таймлайн с формой волны или превью-кадрами
- Перетаскивание маркеров начала и конца
- Быстрая обрезка без перекодирования (stream copy) или точная с перекодированием через ffmpeg.wasm
- Встроенный плеер, клик-сик, воспроизведение фрагмента
- Предпросмотр и ползунок громкости по наведению
- Авто-возврат плеера в границы выделения

### ⬇️ YouTube Качалка
- Вставьте ссылку на YouTube видео
- Показывает название, длительность, просмотры
- Скачивание в MP4 (360p–1080p / Best) или MP3 (128–320 kbps)
- yt-dlp на серверной стороне, файл сохраняется через браузерный диалог

## Установка

### Готовый .exe (Windows)
1. Скачайте `MTools.exe` из [релизов](https://github.com/ваш-username/ваш-репозиторий/releases)
2. Запустите — откроется браузер с приложением

### Из исходников (Python)
```bash
pip install yt-dlp PyInstaller
git clone https://github.com/ваш-username/ваш-репозиторий
cd MTools
python server.py
```

## Сборка .exe
```bash
pip install yt-dlp PyInstaller
pyinstaller build.spec
```

## Технологии
- **Бэкенд:** Python + http.server + yt-dlp (скачивание YouTube)
- **Фронтенд:** Vanilla JS, ffmpeg.wasm (обрезка в браузере)
- **Сборка:** PyInstaller (no-console, иконка mt.ico)
